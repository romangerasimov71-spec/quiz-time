# Как устроены тесты и как добавить новый

Движок (`js/app.js`) ничего не знает о конкретных тестах. Каждый тест — свой файл
в `tests/`, который добавляет себя в общий список `window.QUIZ_TESTS`.

## Новый тест
1. Скопировать любой файл из `tests/` (например `tests/nature.js`) под новым именем.
2. Поменять `id` (латиницей, уникальный), название, цвета, вопросы и звания.
3. Добавить в `index.html` одну строку рядом с остальными тестами:
   `<script src="tests/новый.js"></script>` (порядок строк не важен — см. «Порядок на главном»).
4. Если тест должен стоять на главном не в конце — вписать его `id` в список
   `TEST_ORDER` в начале `js/app.js`.
5. Запустить проверку: `node tools/check.js` — она сама найдёт новый тест, проверит
   его файл и пройдёт его.
6. Перерисовать обложку ссылки: `node tools/make-images.js` (и сохранить `img/`).

## Формат файла
```js
(window.QUIZ_TESTS = window.QUIZ_TESTS || []).push({
  id: 'nature',                 // латиницей; он же в ссылке ?test=nature
  title: 'Природа',             // название на карточке и в картинке «Поделиться»
  subtitle: 'Звери, птицы…',    // строка под названием на карточке
  intro: 'О чём тест…',         // одна строка на заставке перед первым вопросом
  emoji: '🌳',                  // значок теста (лучше старые эмодзи — их видят все телефоны)
  color: '#2e7d32', color2: '#66bb6a',   // цвет теста (градиент)
  questions: [
    // обычный вопрос: 4 варианта, ПЕРВЫЙ — верный (движок перемешивает сам)
    // d — сложность: 1 лёгкий, 2 средний, 3 трудный (без d считается 2)
    { q: 'Текст вопроса?', a: ['верный', 'неверный', 'неверный', 'неверный'],
      fact: 'Строка «А вы знали?» — показывается после ответа.', d: 1 },

    // вопрос «запомни»: набор show показывается seconds секунд, потом прячется
    { type: 'memory', show: ['🍎', '🍌', '🍇'], cols: 3, seconds: 4,
      q: 'Чего не было?', a: ['🍐', '🍎', '🍌', '🍇'] }
    // в show: эмодзи, '' — пустая клетка, { color: '#e53935' } — цветной кружок
  ],
  ranks: [                      // 4 звания: с какого балла
    { min: 0, title: '…', text: 'короткая фраза' },
    { min: 4, title: '…', text: '…' },
    { min: 7, title: '…', text: '…' },
    { min: 9, title: '…', text: '…' }
  ]
});
```
Необязательно: `correct: 2` в вопросе — если верный не первый (номер с нуля).

## Сколько вопросов и как они выбираются
За одно прохождение — `perRun` вопросов (по умолчанию 10; поле теста, задавать не нужно).
Счёт, звания (0/4/7/9), рекорд и «Вопрос N из 10» считаются из этих 10.

**Тест с запасом (так делаем все обычные тесты):** ровно **50 вопросов** —
20 с `d: 1` (лёгкие: знает почти каждый 40+), 20 с `d: 2` (средние: примерно половина),
10 с `d: 3` (трудные: знатоки). При каждом прохождении движок берёт случайные
**4 лёгких + 4 средних + 2 трудных** и ставит их от лёгких к трудным (внутри группы
вперемешку). Если в какой-то группе не хватает — добирает из соседней.
Порядок вопросов в файле не важен.

Чтобы вопросы не повторялись: движок помнит (в `localStorage`, ключ
`quiz-time:recent:<id>`), какие вопросы были в двух последних прохождениях этого теста,
и берёт в первую очередь другие. При 50 вопросах три прохождения подряд — без единого
повтора. Нет хранилища (приватный режим) — помнит до закрытия страницы.

На главном и на заставке пишется «10 вопросов», на заставке ещё строка «Каждый раз — новые вопросы».

**Тест без запаса (10 вопросов или меньше, как «Проверь память»):** берутся все.
Пишите от лёгких к трудным: движок перемешивает вопросы внутри первой и второй половины
(лёгкие остаются в начале). `keepOrder: true` у теста — не перемешивать вовсе.

`tools/check.js` проверяет файл теста с запасом: ровно 50, по сложности 20/20/10,
4 разных варианта, вопросы не повторяются, вопрос ≤ 120 символов, вариант ≤ 40,
есть «А вы знали?», звания 0/4/7/9, белый текст на `color` и `color2` с контрастом ≥ 4,5:1,
цвет не повторяет другой тест. И гоняет выбор 100 раз: всегда 10, 4/4/2, без повторов.

## Порядок на главном
Один список `TEST_ORDER` в начале `js/app.js` (по `id`):
СССР, Песни лохматых годов, Кино, Угадай фильм по цитате, Актёры, Мультфильмы,
Новый год, Транспорт СССР, Города, Природа, Проверь память
(`ussr, songs, kino, quotes, actors, cartoons, newyear, transport, cities, nature, memory`).
Сначала самые массовые. Теста нет в `index.html` — он просто пропускается; тест, которого
нет в списке, встаёт в конец. На компьютере клавиши 1–9 открывают первые девять тестов.

Генерируемый вопрос: вместо готового объекта — `{ make: function () { return {...вопрос...}; } }`.
Движок вызывает `make()` в начале каждого прохождения. Так сделан весь тест
«Проверь память» (`tests/memory.js`): предметы, количества и места каждый раз новые,
верный ответ вычисляется из показанного. Поле `kind` помогает `tools/check.js`
проверить, что ответ действительно следует из картинки.

## Где что
- `js/app.js` — экраны и логика прохождения;
- `js/share.js` — «Поделиться» (одна функция `share()`, сюда потом встанут ВК и ОК);
- `js/sound.js` — звуки верно/неверно и кнопка звука;
- `js/storage.js` — лучший результат, настройка звука и «какие вопросы уже были»
  (localStorage, с защитой);
- `tools/check.js` — автоматическая проверка в браузере (`node tools/check.js`,
  со скриншотами: `node tools/check.js --shots папка`, только данные и доп. проверки:
  `--extra-only`; весь прогон с 11 тестами — около 10 минут: все тесты проходятся
  на телефоне-портрете, на альбоме и компьютере — первый тест и «Проверь память»);
- `tools/make-images.js` — рисует `img/og-cover.png` (превью ссылки) и
  `img/apple-touch-icon.png` (на обложке «10+ тестов», первые 5 тестов по `TEST_ORDER`
  и плитка «и ещё N»); запускать после добавления тестов и смены названий/цветов.
