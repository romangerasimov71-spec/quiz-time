# Передача дел: выкладка «Викторин» в ВК и ОК

Для «директора студии» — чата Романа со встроенным браузером Мака (Claude Desktop). Составлено 13 ноя 2026,
обновлено 13 ноя после проверки Толика по правилам ВК и ОК (поддержка, тексты без брендов, скриншоты, тип, кабинет ИП).
Если ты в облачной сессии без браузера Мака — сюда не лезь, перешли Роману: «Выложи Викторины (quiz-time) по docs/HANDOFF.md».

## Что решено
- Роман говорит **«выкладывай»** — это одно «да» на всю выкладку в ВК и ОК, переспрашивать не нужно.
  ⛔ только то, что может лишь Роман (список ниже). Платное продвижение и посты-бонусы — отдельное «да».
- Только ВК и ОК (одна заявка, ОК привязывается к игре ВК). Playgama не трогаем. Язык — русский.
- Графика кодом, Higgsfield не трогаем. Код приложения не менять, кроме `config.js` (адреса и версия).
- **Тип приложения — «Мини-приложение», НЕ «Игра».** Требования каталога игр ВК (прохождение дольше 10 минут,
  не «сборник текстов») викторинам не подходят — заявку «Игрой» отклонят.
- **Кабинет выплат — кабинет ИП** (как в `game-studio/docs/PUBLISH.md`, п. 8): физлицо больше не принимается.
  Если кабинет требует монетизацию до подачи («Если планируете показывать рекламу… должна быть подключена
  монетизация. Иначе заявка будет отклонена») — подключить её **до** подачи.
- **Поддержка** (ВК п. 2.4.1, ОК п. 1.6): в приложении внизу главного экрана строка «Помощь и вопросы — пишите нам»
  (`SUPPORT` в `config.js`): во ВК открывает https://vk.com/club243202759, в ОК — https://ok.ru/group/70000061487179
  (в ОК нигде нет ссылки на ВК и слова «ВКонтакте»).

## Шаги (кабинет dev.vk.ru; если не открывается — VPN, профиль «ВК напрямую»)
1. **Создать приложение.** `dev.vk.ru` → Приложения → Создать → тип **«Мини-приложение»** (не «Игра»!), название из `release/vk/texts.md`.
   ⛔ Роман подтверждает (SMS — см. PUBLISH.md п. 1). Записать ID.
2. **Информация.** Краткое описание, описание, слоган, Company Name (ФИО — из анкеты кабинета выплат ИП; в репозиторий не писать). Сохранить («Сохранить» бледная — уже сохранено).
   Поле **«Сообщество»** — сообщество студии «Уютные игры» https://vk.com/club243202759 (контакты для пользователей,
   ВК п. 2.4.2). Если навык `vk-games-publish` советует оставить пустым — у нас главнее правило студии из PUBLISH.md («Поддержка»).
3. **Размещение.** Статус «Включено». URL для мобильного приложения, Web и мобильной версии — `https://romangerasimov71-spec.github.io/quiz-time/`
   (хостинг ВК не нужен: так же сделано в «Соннике»; загрузка архива — запасной вариант, если ВК откажет GitHub Pages). Открыть `vk.ru/app<ID>` и убедиться, что приложение грузится.
4. **Отображение.** Книжная; элементы управления — «Над окном»; адаптация под iPhone — «Отключена».
5. **Оформление.** Иконка `icons/icon-576.png` (галочки оставить), фавикон `favicon-32.png` (до 50 КБ), сниппет `snippet-1120x630.png`, скриншоты из `screens/` (переключить на «Книжная», 600×1200, по одному, после каждого — перезагрузить страницу; минимум 3, грузим 5: главный, вопрос, результат, ответ с «А вы знали?», «Проверь память» — на них нет названий площадок и адресов).
   Кабинет мини-приложений может не сохранить 4-й и 5-й («Загрузить ещё», PUBLISH.md п. 5) — тогда хватает трёх: 1, 2, 3. Видео, анимированную иконку, цвет запуска — пропустить. Файлы в страницу — fetch с raw.githubusercontent.com → File → DataTransfer.
6. **Правовые документы.** «Использовать типовые документы».
7. **Монетизация и кабинет выплат.** Кабинет выплат — **кабинет ИП** (PUBLISH.md п. 8): если он уже одобрен для других
   приложений студии — в cashout.vk.ru → Исполнители → Сервисы и игры выбрать исполнителем кабинет ИП для «Викторин»;
   иначе ⛔ анкету ИП заполняет Роман. Если «Модерация» требует подключённую монетизацию до подачи — подключить рекламу
   **до** подачи (иначе заявку отклонят); если ВК даёт включить рекламу только после одобрения — включить сразу после.
   В приложении места уже настроены: награда `hint` («50 на 50») и баннер `bottom` — в `playgama-bridge-config.json`, править не нужно.
8. **Адреса в `config.js` — ДО подачи на модерацию.** Вписать `APP_URL.vk = "https://vk.com/app<ID>"` (ссылка на тест будет `…#test=ussr`). Поднять `version` (1.0.0 → 1.0.1). Commit в `main` и `git push origin main:gh-pages`, дождаться обновления GitHub Pages (проверить, что на ссылке новая версия: curl с `?x=случайное`).
   Пока адрес не вписан, внутри ВК/ОК «Поделиться» и «Скопировать» дают только текст результата, без ссылки.
9. **Одноклассники.** «Другие площадки» → напротив ОК «Опубликовать» → ⛔ **Роман** жмёт и принимает соглашение ОК. «OK API Error» — глюк: обновить страницу; если стоит «ID профиля» — привязано. Когда ОК выдаст адрес, вписать `APP_URL.ok = "https://ok.ru/game/<ID ОК>"` в `config.js`, version +1, push (как в шаге 8) — тоже **до** подачи.
   **Иконка в ОК:** ОК п. 4.5 требует название на логотипе. Посмотреть, что показывает кабинет ОК; если придирается —
   сделать вариант иконки с надписью «Викторины» (`tools/release-art.js`, графика кодом) и загрузить.
10. **Проверить внутри ВК и ОК до подачи** — раздел ниже, все 13 пунктов.
11. **Модерация.** Сначала прочитать **все красные пункты** «Модерации» (они кликабельны — показывают, что не так) и исправить.
    Когда все зелёные — **одна заявка**: площадки ВКонтакте и Одноклассники. Заявка входит в «выкладывай».
    После подачи — следить за «Чатом с модератором» и отвечать за 3 дня; пользователям в сообществе — за 7 дней.
12. **Отчёт.** `game-studio/STATUS.md` (ссылки ВК и ОК), карточка `quiz-time` на доске (`link`), лента; commit + push в `main` игры и `game-studio`.

## Проверить внутри ВК и ОК до подачи (список Толика)
Реклама — настоящая только после включения монетизации; имитации (`?fakead…`) внутри ВК/ОК не работают.
1. Тип приложения в кабинете — «Мини-приложение» (не «Игра»).
2. Прочитать все красные пункты «Модерации» до подачи.
3. Монетизация подключена (если кабинет требует до подачи), исполнитель — кабинет ИП.
4. `vk.ru/app<ID>` и `ok.ru/game/<ID>` на телефоне и компьютере: грузится быстро, сначала заставка «Викторины / Загружаем…», **без логотипа Playgama**.
5. Настоящий баннер внизу не закрывает вопрос и ответы; окна «Выйти из теста?», «Поделиться», «Загружаем рекламу…» — над баннером.
6. «50 на 50»: после досмотра рекламы убраны два неверных ответа; закрыли рекламу раньше — подсказки нет.
7. «Поделиться»: в ВК — только ВК, в ОК — только ОК; ссылка `vk.com/app<ID>#test=…` / `ok.ru/game/<ID>#test=…`, открывает заставку того же теста; на картинке результата нет github.io.
8. iPhone и Android: без прокрутки вбок, безопасные зоны (чёлка, полоска внизу), «назад» ведёт на главный, кнопки ВК «Над окном» не закрывают «‹ Тесты» и звук.
9. Сохранение рекорда после перезапуска — в ВК и в ОК.
10. Поддержка: «Помощь и вопросы — пишите нам» внизу главного; в ВК открывается сообщество ВК, в ОК — группа ОК, нигде в ОК нет ссылки на ВК.
11. Иконка в ОК (название на логотипе — ОК п. 4.5).
12. «В избранное» — только на площадке, с 3-го дня заходов (сразу не появится — это нормально).
13. После подачи — следить за «Чатом с модератором», отвечать за 3 дня; пользователям — за 7 дней.
Плюс: «Тест дня» на главном, «Новинка» на непройденных.
