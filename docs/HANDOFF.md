# Передача дел: выкладка «Викторин» в ВК и ОК

Для «директора студии» — чата Романа со встроенным браузером Мака (Claude Desktop). Составлено 13 ноя 2026.
Если ты в облачной сессии без браузера Мака — сюда не лезь, перешли Роману: «Выложи Викторины (quiz-time) по docs/HANDOFF.md».

## Что решено
- Роман говорит **«выкладывай»** — это одно «да» на всю выкладку в ВК и ОК, переспрашивать не нужно.
  ⛔ только то, что может лишь Роман (список ниже). Платное продвижение и посты-бонусы — отдельное «да».
- Только ВК и ОК (одна заявка, ОК привязывается к игре ВК). Playgama не трогаем. Язык — русский.
- Графика кодом, Higgsfield не трогаем. Код приложения не менять, кроме `config.js` (адреса и версия).

## Где всё
- Репозиторий `romangerasimov71-spec/quiz-time`, ветка `main` (публичный). Адрес приложения: https://romangerasimov71-spec.github.io/quiz-time/
- Пакет: `release/vk/` — `texts.md`, `icons/`, `favicon-32.png`, `snippet-1120x630.png`, `screens/` (5 шт.), `CHECKLIST.md`.
- Правила приложения — `CLAUDE.md`; площадка, баннер, реклама — `docs/PLATFORM.md`; отметки статистики — `docs/analytics.md`.
- Проверки (облачная сессия): `node tools/check.js`, `node tools/check-platform.js`, набор рекламы `tools/ads-test/` — пройдены.

## Шаги (кабинет dev.vk.ru; если не открывается — VPN, профиль «ВК напрямую»)
1. **Создать приложение.** `dev.vk.ru` → Приложения → Создать → тип «Игра» (если есть «Мини-приложение» — его), название из `release/vk/texts.md`.
   ⛔ Роман подтверждает на телефоне (пуш/SMS). Записать ID.
2. **Информация.** Краткое описание, описание, слоган, Company Name (ФИО — из анкеты кабинета выплат; в репозиторий не писать). Сохранить («Сохранить» бледная — уже сохранено).
3. **Размещение.** Статус «Включено». URL для мобильного приложения, Web и мобильной версии — `https://romangerasimov71-spec.github.io/quiz-time/`
   (хостинг ВК не нужен: так же сделано в «Соннике»; загрузка архива — запасной вариант, если ВК откажет GitHub Pages). Открыть `vk.ru/app<ID>` и убедиться, что приложение грузится.
4. **Отображение.** Книжная; элементы управления — «Над окном»; адаптация под iPhone — «Отключена».
5. **Оформление.** Иконка `icons/icon-576.png` (галочки оставить), фавикон `favicon-32.png` (до 50 КБ), сниппет `snippet-1120x630.png`, скриншоты из `screens/` (переключить на «Книжная», 600×1200, по одному, после каждого — перезагрузить страницу; минимум 3, грузим 5). Видео, анимированную иконку, цвет запуска — пропустить. Файлы в страницу — fetch с raw.githubusercontent.com → File → DataTransfer.
6. **Правовые документы.** «Использовать типовые документы».
7. **Реклама.** В «Монетизации» включить рекламу (после одобрения модерации; до этого ВК рекламу не отдаёт). В приложении места уже настроены: награда `hint` («50 на 50») и баннер `bottom` — в `playgama-bridge-config.json`, править не нужно.
8. **Адреса в `config.js`.** Вписать `APP_URL.vk = "https://vk.com/app<ID>"` (ссылка на тест будет `…#test=ussr`). Поднять `version` (1.0.0 → 1.0.1). Commit в `main` и `git push origin main:gh-pages`, дождаться обновления GitHub Pages (проверить, что на ссылке новая версия: curl с `?x=случайное`).
9. **Одноклассники.** «Другие площадки» → напротив ОК «Опубликовать» → ⛔ **Роман** жмёт и принимает соглашение ОК. «OK API Error» — глюк: обновить страницу; если стоит «ID профиля» — привязано. Когда ОК выдаст адрес, вписать `APP_URL.ok = "https://ok.ru/game/<ID ОК>"` в `config.js`, version +1, push (как в шаге 8).
10. **Проверить внутри ВК и ОК** (на телефоне и на компьютере):
    - приложение открывается, тест проходится, рекорд сохраняется после перезапуска;
    - внизу баннер, он не закрывает вопрос и кнопки ответов; окна («Выйти из теста?», «Поделиться») над баннером;
    - кнопка «50 на 50 (за рекламу)»: реклама показывается, после досмотра убраны два неверных ответа; закрыли раньше — подсказки нет;
    - «Поделиться результатом» → ВКонтакте / Одноклассники: ссылка ведёт на приложение в ВК/ОК (а не на github.io), переход по ней открывает заставку того же теста;
    - «Тест дня» на главном; «Новинка» на непройденных; предложение «в избранное» — с 3-го дня заходов (сразу не появится, это нормально).
    Реклама — настоящая только после включения монетизации; имитации (`?fakead…`) внутри ВК/ОК не работают.
11. **Модерация.** Когда все пункты зелёные — **одна заявка**: площадки ВКонтакте и Одноклассники. Красные пункты кликабельны — показывают, что не так. Заявка входит в «выкладывай».
    Кабинет выплат: если анкета физлица уже одобрена (для «Сонника») — повторно не нужна; иначе ⛔ заполняет Роман.
12. **Отчёт.** `game-studio/STATUS.md` (ссылки ВК и ОК), карточка `quiz-time` на доске (`link`), лента; commit + push в `main` игры и `game-studio`.
