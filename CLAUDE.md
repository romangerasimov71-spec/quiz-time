# Викторины (quiz-time) — мини-приложение для ВК и ОК

Не игра, а мини-приложение: один движок викторин, много тестов. Человек проходит
тест, видит результат и делится им с друзьями — так приложение растёт.

Правила работы студии — в репозитории `romangerasimov71-spec/game-studio` (`CLAUDE.md`).
Здесь — всё про само приложение. Общаемся с Романом по-русски, просто.

## Для кого
- В первую очередь Одноклассники: люди старше 40, телефон, крупный шрифт,
  понятно без объяснений. Потом ВК.
- Деньги потом: реклама (за бонус и баннер) + покупки за голоса/ОКи
  (после одобрения кабинета выплат). В прототипе ничего этого нет.

## Решения Романа (не переделывать обратно)
- 10 ноя: идея выбрана. Всё без своего сервера: вопросы и картинки готовятся
  заранее, графика кодом. Higgsfield не трогать.
- 10 ноя, прототип: один движок + 5 тестов по 10 вопросов — «СССР», «Кино»,
  «Новый год», «Проверь память», «Природа». Экран результата и «поделиться
  результатом». Оформление кодом. Без SDK площадок, рекламы и перевода
  (только русский).
- 11 ноя, ответы Романа по прототипу (к полной сборке):
  - ссылка из «Поделиться» ведёт на заставку того же теста (как сейчас);
  - в каждом тесте 20–30 вопросов, при каждом прохождении 10 случайных;
  - звание «Рассеянный с улицы Бассейной» (память, 0–3) — оставить;
  - добавить тесты: «Советские песни и эстрада», «Мультфильмы»,
    «Угадай фильм по цитате».

## Тестовая ссылка
GitHub Pages публикуется с ветки `gh-pages` (копия `main`): после каждой
правки в `main` обновлять и её (`git push origin main:gh-pages`).

## Как устроено
- `index.html` в корне — приложение (GitHub Pages с ветки `main`).
- Тесты — отдельные файлы данных, чтобы новый тест добавлялся без правки движка.
- Подробности прототипа — `docs/PROTOTYPE.md`.
- Формат тестов и как добавить новый — `docs/TESTS.md`.
- Автопроверка в браузере: `node tools/check.js` (нужен Playwright с Chromium).
